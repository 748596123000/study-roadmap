编程与软件工程基础

1.1 为什么还要学「软件工程」层

你已经会 Python / 数据结构 / 网络 / PyTorch，这些是「算法与计算」能力。但做正规软件还需要「工程能力」：用 Git 管理版本、用虚拟环境隔离依赖、写单元测试、学会调试与阅读他人代码。这是从「写脚本」到「做项目」的分水岭。

1.2 定点补强清单（可勾选，勾完自动记进度）

1.3 阶段实战任务（必须完成才算过关）

任务 1 · 版本化你的旧项目

挑一个你以前写过的 Python 或 PyTorch 项目，用 Git 初始化、分几次 commit、开一个分支加新功能再 merge 回主干，最后推到 GitHub。

任务 2 · 写一个带测试的小工具

写一个「JSON 配置读取 + 数据处理」的命令行小工具，用 pytest 写 5 个以上断言，验证输入输出。

✅ 阶段目标：能用 Git 管理代码，项目能装到任何一台机器上跑起来。

2.1 前端全景与选型

主流前端框架三选一：React（生态最广，大厂与开源项目主力）、Vue 3（上手友好、中文生态好、国内大厂占比高）、Angular（强约束，较少）。对从后端转前端的你，先学 Vue 3 最快，会 Vue 后再转 React 很顺。

6.1 大模型应用框架与架构

RAG 检索增强Agent 智能体 LangChainLlamaIndexDify Prompt 工程OpenAI APILangGraph

这是你整个学习方向里最值得投入的板块，也是当前就业/项目蓝海，三条主线：

  • RAG（检索增强生成）：私有知识库 → 向量化 → 检索 → 喂给大模型，解决幻觉与私有数据问题。
  • Agent（智能体）：大模型 + 工具调用，让它自动规划步骤、执行任务。
  • AI 工作流：串联多个 AI 能力，如「上传合同 → OCR → 大模型提取 → 入库」。

方案 A GitHub Pages（推荐，最稳定）

把文件放进新的 GitHub 仓库

登录 github.com → New repository → 命名如 study-route（设为 Public）→ 上传本机这个 HTML 文件，并重命名为 index.html。

开启 Pages

仓库 Settings → Pages → Source 选 Deploy from a branch → 选 main 分支 + / (root) → Save。

等 1–2 分钟，打开你的网址

地址：https://你的用户名.github.io/study-route/
第一次部署后会自动给你一个专属 URL。

方案 B Netlify Drop（最简单，拖拽即上线）

打开 app.netlify.com/drop

用邮箱或 GitHub 免费注册并登录 Netlify 账号。

把 HTML 拖进去

拖入后自动生成一个 https://随机名.netlify.app 地址，立即访问；在站点设置里可改个好记的子域名。

小提示 让部署更专业

  • 把文件改名为 index.html 后，访问根路径更干净（无需写文件名）。
  • 想绑定自己的域名？GitHub Pages / Netlify 都支持在设置里绑一个你买的域名（域名这一步才收费）。
  • 这个文档不含任何后端，纯静态，三个平台都能直接托。
✅ 部署完成：以后用手机或任何设备打开那个网址就能随时查看学习路线。注意：勾选进度存在各设备浏览器本地，不跨设备同步。
